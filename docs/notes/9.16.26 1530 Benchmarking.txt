To find each customer's **second most recent order date**, we can use a **window function** in SQL. The idea is to:

1. Order each customer's orders by `order_date` in descending order (most recent first).
2. Use a window function to assign a **rank** to each order per customer (rank = 1 for most recent, 2 for second most recent, etc.).
3. Filter only those with rank = 2 (the second most recent).

Here's the SQL query:

```sql
SELECT 
    customer_id,
    order_date
FROM (
    SELECT 
        customer_id,
        order_date,
        RANK() OVER (PARTITION BY customer_id ORDER BY order_date DESC) AS order_rank
    FROM orders
) ranked_orders
WHERE order_rank = 2;
```

---

### Explanation:

- `PARTITION BY customer_id`: Groups the data by customer so that each customer's orders are considered separately.
- `ORDER BY order_date DESC`: Orders each customer's orders from most recent to oldest.
- `RANK()`: Assigns a rank to each order within the partition. The most recent order gets rank 1, the next gets rank 2, etc.
- `WHERE order_rank = 2`: Selects only the second most recent order per customer.

---

### Notes:

- This assumes that each customer has **at least two orders**. If a customer has only one order, they won't appear in the result (since rank 2 doesn't exist).
- If you want to include customers with only one order (and return `NULL` or a placeholder), you'd need a different approach (e.g., using `DENSE_RANK()` or a `LEFT JOIN` with a subquery). But based on the requirement ("second most recent"), we assume at least two orders per customer.
